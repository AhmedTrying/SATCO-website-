# SATCO website and dashboard QA — 24 September 2026

## Scope and result

Tested the deployed public site and dashboard, plus production builds and write flows in an isolated local copy (`C:\satco-dev\satco-qa-20260924`). The main repository's content and database were not changed by test submissions. Both apps linted successfully. With a clean install and the Windows build root corrected in the isolated copy, both apps type-checked and built successfully. The public export generated 40 static pages; the admin build generated its server routes and public APIs.

All 12 main public routes opened with one `h1`, no horizontal overflow at a 375px browser viewport, and no broken images among images loaded at inspection time. Careers keyword search returned the expected matching role and empty state. Role detail and application pages loaded, the application form has field labels, required-field validation focused the first invalid field, and the mobile menu closed with Escape and restored focus. Eleven dashboard sections opened under the local Admin role. The dashboard rejected an unauthenticated private-media request (401), redirected unauthenticated protected pages to login, rejected a disallowed application origin (403), rejected an unknown job (404), and accepted a valid synthetic local application (201). A local homepage draft appeared in the Publish center; publishing updated the site's generated `home.json` snapshot.

These checks are broad functional coverage, not a full WCAG audit, load test, or cross-browser certification. No live CV upload, real email delivery, or production content mutation was attempted.
